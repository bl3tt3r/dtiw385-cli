dtiw385 est un outil en ligne de commande qui détecte et interroge vos décodeurs DTIW385 sur votre réseau local — idéal pour l'automatisation, la domotique et les scripts.

dtiw385 is a command-line tool that discovers and queries DTIW385 decoders on your local network — perfect for automation, home control, and scripting.

📦 InstallerInstall ⭐ GitHub
bash
# Découverte des décodeurs sur le réseau
# Discover decoders on the network
$ dtiw385 scan --ip-range 192.168.1.0-192.168.1.255 --port-range 8080-8090
{"ip":"192.168.1.10","port":8080}
{"ip":"192.168.1.42","port":8085}

# Interroger tous les décodeurs trouvés d'un coup
# Query all discovered decoders at once
$ dtiw385 scan --ip-range 192.168.1.0-192.168.1.255 --port-range 8080-8090 | dtiw385 infos
{"ip":"192.168.1.10","port":8080,"firmware":"1.4.2",...}
{"ip":"192.168.1.42","port":8085,"firmware":"1.4.1",...}

Pipelines NDJSON

Chain commands with Unix pipes: the output of scan feeds directly into infos, no extra config needed.

Comment ça marche
How it works

Simple comme un pipe.

As simple as a pipe.

01

Installez l'outil

Install the tool

Une seule commande Cargo suffit : cargo install dtiw385-cli. Aucune dépendance externe.

One Cargo command is all it takes: cargo install dtiw385-cli. No external dependencies.

02

Scannez votre réseau

Scan your network

Lancez scan avec une plage d'IP et de ports. Chaque décodeur trouvé s'affiche instantanément en JSON.

Run scan with an IP and port range. Every discovered decoder appears instantly as a JSON line.

03

Chaînez et automatisez

Chain and automate

Connectez la sortie de scan à infos ou à vos propres scripts. Le format JSON est lisible par n'importe quel outil.

Pipe the output of scan into infos or your own scripts. JSON is readable by any tool.
